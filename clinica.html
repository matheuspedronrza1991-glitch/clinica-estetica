⚙️ Configurar Firebase

Cole abaixo as credenciais do seu projeto Firebase para conectar o sistema.
Veja o passo a passo no final desta página.

📋 Como criar seu Firebase gratuito (5 minutos)
1. Acesse console.firebase.google.com
2. Clique em "Criar um projeto" → dê um nome (ex: clinica-estetica)
3. Desative o Google Analytics (opcional) → clique em Criar projeto
4. No menu lateral clique em Firestore Database → Criar banco de dados
5. Escolha Modo de teste → selecione a região southamerica-east1
6. Volte à tela inicial do projeto → clique em </> Web → registre o app
7. Copie as credenciais que aparecem (apiKey, authDomain, etc.) e cole acima
8. Clique em Conectar ao Firebase — pronto! 🎉
